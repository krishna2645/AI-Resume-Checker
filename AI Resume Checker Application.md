# AI Resume Checker Application (download project)

## 📌 Overview
The **AI Resume Checker** is a smart application designed to help candidates and recruiters evaluate resumes efficiently.  
It leverages **Gemini-based ATS analysis** to provide accurate insights and ranking for multiple resumes.

---

## 🚀 Features
- Account Creation & Authentication  
- Resume Upload (PDF/DOCX)  
- Gemini-Powered ATS Analysis  
- Saved Scan History  
- Dashboard Analytics  
- Profile Management  
- Settings & Preferences  
- Multi-Resume Candidate Ranking  

---

## 🛠️ Tech Stack
- **Frontend:** React.js / Next.js  
- **Backend:** Node.js / Express.js  
- **Database:** MongoDB / PostgreSQL  
- **AI Model:** Google Gemini API  
- **Cloud Storage:** Google Drive integration  

---

## 📊 Workflow
1. User Registration/Login  
2. Resume Upload  
3. Gemini ATS Analysis  
4. Results Display (Dashboard)  
5. History Saved for Future Reference  
6. Multi-Resume Ranking for Recruiters
